# Calidad de datos

Requisitos para poder medir y categorizar la calidad de los datos cargados en la plataforma, pendientes de definir en detalle.

- Trazabilidad del dato: quién lo sube y cómo fue capturado.
- Categorización de calidad de datos para medir el error.
- Revisión de los modelos de datos de cobertura: ubicar las referencias de datos (de dónde vienen las coberturas y los estados).
