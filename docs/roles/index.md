# Roles de la plataforma

Colflux usa una cascada de niveles de acceso: cada nivel incluye los permisos de los anteriores.

| Nivel | Puede hacer | Pestañas adicionales en el menú |
|-------|-------------|----------------------------------|
| **Ciudadano** | Consultar mapas y datos públicos | Inicio, Mapas, Datos |
| **Investigador** | Lo anterior + descargar datos | + Modelo de datos |
| **Reportador** | Lo anterior + subir datos de campo | + Reportar, Gestión de datos |
| **Administrador** | Lo anterior + gestión del equipo y usuarios | + Equipo |

El nivel de un usuario se solicita desde su perfil y lo aprueba un administrador en la pestaña **Equipo**.
