# Prompt de identidad visual (para IA / nuevos repos)

Copia y pega este bloque al iniciar un proyecto, sitio o repo nuevo de COLFLUX, para que una IA (o cualquier colaborador) aplique la identidad visual correcta desde el principio.

```
Este proyecto pertenece a COLFLUX. Al definir estilos visuales (CSS, temas,
presentaciones, gráficas, UI), usa estos lineamientos de marca:

COLORES INSTITUCIONALES
Principales:
- Verde azulado (Vida):  #198A77
- Verde (Vida):          #739E5B
- Amarillo (Energía):    #F2B91B

Secundarios:
- Café oscuro (Suelo/Carbono): #57270F
- Naranja (Energía):           #DF5B26
- Naranja claro (Energía):     #F19F1F

Uso: el verde azulado (#198A77) es el color primario (navegación, enlaces,
elementos interactivos). El amarillo (#F2B91B) es el color de acento
(hover, highlights, llamados a la acción). Los demás colores son de apoyo
para gráficas, categorías o piezas editoriales — no para UI base.

TIPOGRAFÍA
- IBM Plex Sans Bold está reservada EXCLUSIVAMENTE para el logotipo. No la
  uses en cuerpo de texto ni interfaces.
- Para texto e interfaces, usa una sans serif limpia y de alta legibilidad
  (ej. Inter, system-ui). Prioriza contraste y espaciado generoso.

ESTÉTICA
- Minimalista, limpia, mucho espacio en blanco.
- Evita sombras, degradados o efectos decorativos pesados — la identidad
  de COLFLUX es técnica/científica, no corporativa ni recargada.
- Los colores deben evocar tránsito y flujo (carbono, ecosistemas), no
  usarse como bloques planos saturados en toda la interfaz: resérvalos
  para acentos, no para fondos completos salvo piezas puntuales.

LOGOTIPO (si aplica)
- No estirar, rotar, recolorear ni aplicar efectos al logotipo.
- Reducción mínima: 140px digital / 2.5cm impresión (logotipo completo);
  80px digital / 1.5cm impresión (isotipo solo).
- Ubicación preferente: esquina superior o inferior derecha; centrado
  arriba en piezas institucionales formales.

Fuente completa: manual de identidad visual en docs/marca/ del repo
colflux/context.
```
