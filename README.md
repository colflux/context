# Colflux — Documentación transversal

Documentación central del componente de plataforma (OE2) de Colflux, publicada como wiki en GitHub Pages y usada como contexto en conversaciones con IA.

## Estructura

- `docs/requisitos/` — requisitos técnicos
- `docs/arquitectura/` — decisiones técnicas
- `docs/conceptos/` — glosario y temas de dominio
- `docs/gestion/` — hitos y seguimiento
- `docs/institucional/` — socios y contactos

## Desarrollo local

```
pip install mkdocs-material
mkdocs serve
```

El sitio se publica automáticamente en GitHub Pages al hacer push a `main`.
